UI sweep

Runs ui-lint.js uiSweep() (every tab, every ▾ menu, every menu-bar menu and submenu) in the app at each window width × interface size × text size × theme, in a hidden frame of that size — no window resize needed. Query: ?w=375,768,1280,1920&z=0.7,1,1.5&fs=1,1.15&theme=dark,light&h=800 (&offline=1: in an offline project with four simulated processors, so every tab shows its full controls; &usbauto=1: with the USB line and its button). Saving, sync and processor searches are switched off in the frame; this browser’s size / text / theme settings are put back at the end.
