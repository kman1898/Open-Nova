Offline parity

An offline project (H5, VX1000, VX1000 Pro, MX40 Pro, no hardware): every tab shows its real controls through the simulated processors (drv-offline.js) — no “link it” / “not linked” / “nothing to read” — and the simulated processors answer like the real ones (calibration, monitor, screen settings, presets, schedules, backup, service). Nothing may reach the helper's hardware routes. Add ?audit=1 to list each tab's text.
