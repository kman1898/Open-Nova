# Disclaimer

This disclaimer covers the software, documentation and every other file in this repository and in the releases built
from it (together, "the files").

## It controls live equipment

Open Nova sends commands to LED processors, sending cards and receiving cards: layouts, brightness and colour, test
patterns, blackout, redundancy, receiving-card files and saves to the processor's memory. A wrong command can black out a
wall, show the wrong picture, change settings that survive a restart, or leave cards that need NovaStar's own tools to
recover. Much of Open Nova has only been tested against stand-ins and simulators, not against every processor, card or
firmware version (see [ROADMAP.md](ROADMAP.md)).

Before Open Nova is used on a show, an event, a broadcast or any installation people rely on, a qualified person must
check what it does on that equipment, with a way back (a saved configuration, NovaStar's own software at hand) and away
from an audience. Don't use it on equipment you aren't allowed to change.
